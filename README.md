# Adversarial Machine Learning in Cybersecurity

> Evaluating the robustness of Machine Learning-based Intrusion Detection Systems (IDS) against adversarial attacks using the NSL-KDD dataset.

## Overview

This project investigates how machine learning models perform under adversarial conditions and evaluates defense mechanisms to improve cybersecurity resilience.

## Features

- Intrusion Detection System (IDS) modeling
- FGSM adversarial attacks
- PGD adversarial attacks
- Adversarial training defenses
- Confidence interval analysis

## Models

- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Random Forest
- Convolutional Neural Network (CNN)

## Technologies

- Python
- NumPy
- Pandas
- Scikit-Learn
- TensorFlow/Keras
- Plotly
- Matplotlib
- Adversarial Robustness Toolbox
